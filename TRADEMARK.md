# Handicraft UI Trademark Policy

**The code is MIT licensed. The name is not.**

The MIT License in [LICENSE](LICENSE) grants broad rights to the _software_ — use it, modify it, sell
it, ship it in a commercial product. It grants no rights whatsoever to the project's name, wordmark or
logo. Those are separate, and this document is where they are reserved.

This exists for one reason: so that when someone downloads this library, the thing calling itself
Handicraft UI is the real one.

## The marks

- **Handicraft UI** and **Handicraft** as the name of this project
- The Handicraft UI wordmark and logo
- The `@handicraft` npm scope
- The domain `handicraftui.dev`

## What you may do without asking

Truthful, descriptive reference is always fine. None of this needs permission:

- "Built with Handicraft UI"
- "A theme for Handicraft UI", "Handicraft UI components for Vue"
- "Compatible with Handicraft UI"
- Writing tutorials, reviews, comparisons or criticism that name the project
- Reproducing the name in the copyright and licence notices, as MIT requires

The test is whether a reasonable person would understand you are _referring_ to Handicraft UI rather
than _claiming to be_ Handicraft UI.

## What needs permission

- Naming your fork, product, package or service **Handicraft UI**, or a name close enough to be
  confused with it
- Using the logo or wordmark as the identity of your own project
- Registering a domain, npm scope, social account or organisation name that implies you are this
  project or speak for it
- Anything that suggests the project endorses, sponsors or maintains your work when it does not

## If you fork it

Forking is welcome and MIT explicitly permits it. Give the fork **its own name**.

You must keep the copyright and licence notices — that is the one condition MIT imposes, and it is
what preserves the chain of authorship. Beyond that, the code is yours to take in whatever direction
you like, under a name that is yours.

## Why this is here rather than in the licence

No open source licence can prevent a fork; permitting derivative works is part of the definition. A
licence governs copyright, and copyright covers the code. Names are governed by trademark, which is a
different body of law and has to be asserted separately.

That is how Rust, Kubernetes, Docker and Linux all handle it: permissive code, reserved marks. This
document is that assertion for Handicraft UI.

## Questions

Open an issue, or reach the maintainer through the repository. If you are unsure whether a use is
acceptable, asking first is free and a great deal faster than the alternative.
